# Интернет-магазин — проект № 5

Первая неделя: анализ и проектирование.

Я выбрал небольшой магазин компьютерных аксессуаров. Покупатель сможет посмотреть товары, собрать корзину и оформить заказ. Администратор будет добавлять товары, менять остатки и обрабатывать заказы.

## Как посмотреть

Откройте `docs/week-1-report.docx` в Word или LibreOffice. Диаграмма и макет также доступны отдельно в папке `design`. Для просмотра первой недели Java и MySQL устанавливать не нужно.

## Технологии для следующих этапов

Java 17, Maven, Spring Boot, Spring Web, Spring Data JPA, Hibernate, MySQL, Spring Security. Интерфейс — HTML, CSS и JavaScript с Fetch API. Для статистики — Chart.js, для тестов — JUnit 5 и Spring Boot Test.

Общий срок — 5 недель. В исходном задании указан план на 7 недель, поэтому этапы со второй недели объединены. План находится в отчёте.
