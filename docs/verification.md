# Проверка приложения

Проверка выполнена на Java 21, Maven и настоящем MySQL в отдельной базе.

## Автоматизированные проверки

`mvn package`: успешно. 29 тестов, 0 ошибок, 0 пропусков.

- CRUD категорий и товаров, валидация и обработка ошибок.
- Запрет удаления записей со связями.
- Регистрация роли Customer, хеширование пароля и вход.
- Ограничения административных операций и защита CSRF.
- Раздельные корзины и заказы покупателей.
- Оформление по актуальной цене и очистка корзины.
- Откат всего заказа, если одного товара не хватает.
- Два одновременных заказа на последнюю единицу: один успешный, второй отклоняется.
- Возврат товара на склад один раз при повторной отмене.
- Оплата, возврат, допустимые переходы статусов и статистика.
- Поиск, фильтры и сортировка каталога.
- Обновление старых демонстрационных названий с сохранением id и текущего остатка.
- Сохранность названий и цен позиций уже оформленного заказа при обновлении каталога.
- Повторный запуск каталога без сброса изменённых цен и остатков.

## Проверка в Chrome

Проверены девять реальных моделей и загрузка всех локальных фотографий. Для плавающей корзины проверены открытие, гостевое состояние, выбранные товары, сумма и изменение количества. Escape и нажатие вне окна закрывают корзину.

Проверены оформление из мини-корзины, автоматическое открытие оплаты, заполнение тестовой картой, ошибка на другом номере карты и успешный платёж. В запрос `/pay` карточные данные не передавались. После закрытия форма очищается.

На экране шириной 390 px проверены отсутствие горизонтальной прокрутки и размещение окна корзины внутри экрана. Ошибок JavaScript во время этих сценариев не было.

На предыдущем этапе также проверены поиск, вход покупателя, вход администратора, перевод заказа до COMPLETED и загрузка Chart.js.

## Запуск

Готовый JAR проверен с профилем demo в отдельной базе. Дополнительно успешно запущен `run-local.sh` с постоянной базой из `.local/mysql` и портом приложения 18085. Ответ `/api/products` содержал девять обновлённых моделей.

Обычный запуск: `start.command` или `./run-local.sh`, затем http://localhost:8080. Инструменты и рабочая база находятся в игнорируемой папке `.local`.
