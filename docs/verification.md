# Проверка приложения

Проверка выполнена на Java 21, Maven и настоящем MySQL в отдельной базе.

## Автоматизированные проверки

`mvn package`: успешно. 27 тестов, 0 ошибок, 0 пропусков.

- CRUD категорий и товаров, валидация и обработка ошибок.
- Запрет удаления записей со связями.
- Регистрация только роли Customer, хеширование пароля и вход.
- Запрет доступа к административным операциям для Customer.
- Защита запросов, меняющих данные, через CSRF.
- Раздельные корзины и заказы покупателей.
- Оформление по актуальной цене и очистка корзины.
- Откат всего заказа, если одного товара не хватает.
- Два одновременных заказа на последнюю единицу: один успешный, второй отклоняется. Остаток не становится отрицательным.
- Повторная отмена возвращает товар на склад только один раз.
- Оплата, возврат, допустимые переходы статусов и статистика.
- Поиск, фильтры и сортировка каталога.

## Проверка в Chrome

Проверены загрузка девяти товаров, поиск, вход покупателя, добавление в корзину, оформление заказа, учебная оплата, вход администратора и перевод заказа до статуса COMPLETED. Проверена загрузка Chart.js.

На экране шириной 390 px проверено отсутствие горизонтальной прокрутки. Ошибок JavaScript во время этих сценариев не было.

## Запуск

JAR запускался с профилем demo на временной MySQL-базе. Полный сценарий в браузере выполнен успешно.

Для постоянной базы подготовлены run-local.sh и start.command. Java 21, Maven и зависимости установлены в игнорируемой папке .local на текущем компьютере. Синтаксис скриптов проверен. Сквозной запуск нового скрипта с постоянной базой не выполнен: автоматическая проверка разрешений остановилась из-за лимита расходов рабочего пространства при переключении с временного MySQL.

При завершении проверки временное Java-приложение остановлено. Временный MySQL может оставаться запущенным на порту 33307. Скрипт run-local.sh использует другой порт — 33308.
